# Logistics-Shipment-Analytics-Dashboard
A comprehensive Power BI dashboard project designed to analyze and visualize logistics and shipment operations. This project provides actionable insights into shipment performance, delivery efficiency, transportation costs, fuel consumption, and operational KPIs to support data-driven decision-making in supply chain management.

## Overview
The **Logistics Shipment Analytics Dashboard** is a Power BI project developed to analyze shipment operations, delivery performance, transportation costs, and logistics KPIs. The dashboard provides interactive visualizations and actionable insights to improve supply chain efficiency and support business decision-making.

---

## Key Features
- Interactive Power BI Dashboard
- Shipment Performance Analysis
- On-Time Delivery Tracking
- Fuel Efficiency Monitoring
- Cost per KM Analysis
- Vehicle-wise Logistics Insights
- KPI & Trend Visualization
- Data Cleaning using Power Query
- Advanced DAX Calculations

---

## Tools & Technologies
- **Power BI**
- **DAX (Data Analysis Expressions)**
- **Power Query**
- **Data Visualization**
- **Supply Chain Analytics**

---

## Key Metrics
- Total Shipments
- On-Time Delivery %
- Fuel Consumption
- Transportation Cost
- Distance Covered
- Cost per Kilometer
- Vehicle Performance

---

## Business Insights
- Analyzed shipment delivery trends
- Identified operational inefficiencies
- Monitored logistics performance KPIs
- Evaluated transportation and fuel costs
- Improved visibility into supply chain operations

---

## Project Outcome
This dashboard helps logistics teams and business stakeholders monitor operations effectively, optimize delivery performance, reduce transportation costs, and make data-driven decisions through interactive visual analytics.
